MP4 Lite 1.0 — Windows 11용 MP4 영상 압축
========================================

실행
1. ZIP을 받았다면 먼저 전체 압축을 풉니다.
2. 폴더 안의 MP4Lite.exe를 실행합니다.
   engine 폴더와 MP4Lite.exe.config를 실행 파일 옆에 함께 두세요.
3. [파일 추가] 또는 드래그 앤 드롭으로 MP4를 추가합니다.
4. 720p / 480p / 360p 중 하나를 고릅니다. 기본값은 480p입니다.
5. [압축 시작]을 누릅니다.
6. [결과 폴더 열기]에서 완성된 영상을 확인합니다.

별도 Python, FFmpeg 설치 및 관리자 권한이 필요 없습니다.
Windows 11 x64 및 기본 .NET Framework 4.8 이상에서 동작합니다.
압축은 이 컴퓨터에서 실행되며 영상 업로드나 인터넷 연결이 없습니다.

음질 유지
- 모든 오디오 트랙을 재인코딩하지 않고 그대로 복사합니다(-c:a copy).
- 오디오 코덱, 샘플레이트, 채널 수를 바꾸지 않습니다.
- 오디오를 복사할 수 없는 파일은 오류로 표시합니다.
  다른 음질로 자동 변환하지 않습니다.
- 오디오가 없는 영상도 처리합니다.
- 복사된 오디오 코덱의 재생 지원은 사용하는 플레이어에 따라 다릅니다.

화질
- 720p: 최대 1280 × 720, CRF 28.
- 480p: 최대 854 × 480, CRF 32. 용량을 우선할 때 권장합니다.
- 360p: 최대 640 × 360, CRF 36.
- 세로 영상은 가로·세로 제한값이 반대로 적용됩니다.
- 종횡비를 유지하며 출력 크기는 짝수 픽셀로 맞춥니다.
  예: 1920 × 1080의 480p 결과는 852 × 480입니다.
- 작은 원본은 확대하지 않고 영상 압축률만 변경합니다.
- H.264 / MP4로 저장하며 원래 영상 프레임 시점을 유지합니다.
- HDR(PQ/HLG)은 SDR로 톤 매핑합니다.

저장과 취소
- 기본 저장 위치: 각 원본 파일이 있는 폴더의 '압축완료' 하위 폴더.
- [폴더 선택]을 누르면 원하는 폴더에 저장할 수 있습니다.
- 예: 영상.mp4 → 압축완료\영상_480p.mp4
- 같은 이름이 있으면 (1), (2) 등을 붙여 덮어쓰기를 피합니다.
- 원본은 수정하거나 삭제하지 않습니다.
- [취소]하면 진행 중인 임시 파일을 제거합니다.
  이미 완료된 파일은 그대로 남습니다.
- 완료/실패 행을 두 번 클릭하면 파일 위치/오류 내용을 확인합니다.
- [결과 폴더 열기]는 가장 최근에 완료한 파일의 폴더를 엽니다.

알아둘 점
- 이미 매우 작게 압축된 영상은 결과가 더 커질 수 있습니다.
  이때 화면에 '용량 감소 없음'이라고 표시합니다.
- 음질을 유지하므로 오디오 용량은 줄이지 않습니다.
- 첫 번째 일반 영상 트랙과 모든 오디오 트랙을 저장합니다.
  추가 영상 트랙, 자막, 첨부 이미지, 데이터 트랙은 포함하지 않습니다.
- 실패한 항목은 두 번 클릭하여 상세 메시지를 확인하세요.
- 실행 파일에는 상용 코드 서명이 없습니다.

소스와 구성
- source: 앱 C# 소스, 재빌드 스크립트, 통합 테스트.
- source\Build.ps1: Windows의 기본 C# 컴파일러로 앱을 재빌드합니다.
- engine: FFmpeg 9.0.2와 FFprobe의 변경하지 않은 Windows 실행 파일.
- licenses: 앱 및 변환 엔진의 라이선스와 배포 출처.
- 검증결과.txt: 실제 테스트 결과.
