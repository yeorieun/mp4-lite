# MP4 Lite

**영상은 가볍게, 소리는 그대로.**

Windows 11에서 MP4 영상의 화질을 낮춰 용량을 줄이는 한국어 데스크톱 앱입니다.
오디오는 재인코딩하지 않고 모든 트랙을 그대로 복사합니다.

## 다운로드 및 사용

[Releases에서 실행용 ZIP 받기](../../releases)

ZIP 전체를 압축 해제한 다음 **MP4Lite.exe**를 실행하세요.
engine 폴더와 MP4Lite.exe.config를 실행 파일 옆에 함께 두어야 합니다.

1. **파일 추가** 또는 드래그 앤 드롭으로 MP4를 선택합니다.
2. **720p / 480p / 360p** 중 하나를 고릅니다. 기본값은 480p입니다.
3. **압축 시작**을 누릅니다.
4. **결과 폴더 열기**로 완성된 영상을 확인합니다.

원본을 보관하고 각 원본 위치의 '압축완료' 폴더에 새 파일을 저장합니다.
같은 이름이 있으면 번호를 붙여 기존 파일을 보호합니다.
폴더를 직접 지정하거나 여러 파일을 한 번에 처리할 수도 있습니다.

## 기능

| 설정 | 최대 크기, 가로 영상 기준 | 영상 압축 |
|---|---|---|
| 720p · 가볍게 | 1280 × 720 | H.264, CRF 28 |
| 480p · 작게 | 854 × 480 | H.264, CRF 32 |
| 360p · 아주 작게 | 640 × 360 | H.264, CRF 36 |

- 오디오 코덱, 샘플레이트, 채널 수를 유지하는 스트림 복사.
- 원본 화면 비율 및 프레임 시점 유지, 작은 영상 확대 방지.
- 세로 영상의 회전 정보 처리.
- HDR PQ/HLG 입력은 SDR로 톤 매핑.
- 진행률, 취소, 결과 용량, 항목별 오류 표시.
- 로컬 처리. 영상 업로드나 앱의 인터넷 연결 없음.

출력 크기는 비율을 유지하면서 짝수 픽셀로 맞춥니다.
예를 들어 1920 × 1080의 480p 결과는 852 × 480입니다.

이미 작게 압축된 영상은 결과가 더 커질 수 있으며 앱에 표시됩니다.
오디오 용량은 줄이지 않습니다. 첫 번째 일반 영상 트랙과 모든 오디오 트랙을
저장하며 자막, 추가 영상, 첨부 이미지, 데이터 트랙은 포함하지 않습니다.

## 실행 환경

- Windows 11 x64
- .NET Framework 4.8 이상
- 실행용 ZIP에는 FFmpeg/FFprobe가 포함되어 별도 설치가 필요 없습니다.
- 관리자 권한이 필요하지 않습니다. 실행 파일에는 상용 코드 서명이 없습니다.

## 소스에서 빌드

이 저장소의 Git 이력에는 소스, 문서, 라이선스만 포함합니다.
실행용 ZIP은 Releases에서 제공합니다.

1. Releases의 실행용 ZIP에서 engine 폴더를 저장소 루트에 복사합니다.
   또는 [FFmpeg Windows 빌드](https://www.gyan.dev/ffmpeg/builds/)에서
   ffmpeg.exe와 ffprobe.exe를 받아 engine 폴더에 넣습니다.
2. PowerShell에서 다음을 실행합니다.

       .\source\Build.ps1
       .\MP4Lite.exe

Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.
앱 소스에는 외부 NuGet 의존성이 없습니다.

## 검증

    .\source\Test.ps1

새 임시 폴더에서 테스트 영상을 생성해 검증합니다. 오디오 패킷 SHA-256 일치,
3가지 해상도, 원본 보존, 파일명 충돌, 무음, 회전, 취소, 가변 프레임률,
HDR 변환 및 비정사각형 픽셀 입력에 대한 13개 검사를 수행합니다.
